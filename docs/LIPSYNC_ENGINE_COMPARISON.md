# 口型引擎三方对比：LatentSync vs MuseTalk vs InfiniteTalk

> 2026-08-20 定稿。业务背景：客户真人出镜宣读（手持证件/证书），中文配音对口型；
> 硬性要求 = 背景/身体/手持物**像素级保真** + 嘴型贴合 + 可量产成本。

## 一、结论（人工看片裁决）

| 排名 | 引擎 | 一句话结论 |
|---|---|---|
| 🥇 | **LatentSync 1.6** | 当前最优：局部重绘保背景，嘴型可用，分钟级出片。已进交付链路（c6 参数） |
| 🥈 | **MuseTalk** | 贴合式生成，快但"假"（贴图感）。**待调参翻身验证**（明日开始） |
| 🥉 | **InfiniteTalk** | 出局：14 秒视频跑 5.4 小时，画质偏软，无明显提升。仅留作效果天花板参考 |

## 二、技术路线与硬指标对比

| 维度 | LatentSync 1.6 | MuseTalk | InfiniteTalk (Wan2.1-14B) |
|---|---|---|---|
| 路线 | 扩散**局部重绘**（嘴部 latent 区域） | VAE latent **贴脸替换**（256 分辨率贴回） | 扩散**整帧重新生成**（V2V） |
| 背景保真 | ✅ 非嘴部区域不动 | ✅ 只贴嘴部 | ⚠️ 全帧重生成，证件/文字有漂移风险 |
| 嘴型自然度 | 中上（g1.5+amp1.3 接近可灵） | 中（模板感，闭口音易糊） | 理论上限最高（audio CFG），实测无肉眼可见优势 |
| 画质 | 原生（保留原片清晰度） | 受限于 256 贴图分辨率 | 448×832/409kbps，偏软 |
| 速度(14s, 4090) | **~5-8 分钟** | **秒级~分钟级**（最快） | **5 小时 24 分** ❌ |
| 显存 | ~16GB | <8GB | 11GB（fp8+层流式） |
| 权重体积 | ~9.3GB（云） | ~1.5GB | ~31GB（fp8 路线；全量 70GB+） |
| 部署难度 | 低（setup 脚本一条龙） | 低 | 高（8 层坑，见 experiments/infinitetalk/FIXES.md） |
| 可商用性 | ✅ 已交付 | 待调参验证 | ❌ 成本 50 倍无收益 |

## 三、实验记录索引

### MuseTalk（第一阶段）
- 位置：`external/MuseTalk/`（源码在，权重 8.7GB 已删可重下：`download_weights.sh`）
- 用户结论："太假了，不符合诉求"——假感来源假设：① 贴回边界融合痕迹 ② 256 分辨率上限 ③ 遮挡/侧脸场景贴图穿帮
- **明日调参翻身验证**（见第五节）

### LatentSync 1.6（第二阶段，当前交付）
- 参数演进：c1→c2→c3 基线 → c4(g1.5)/c5(g1.8) A/B → **c6(g1.5 + audio_amp 1.3) 胜出，接近可灵**
- 交付配置：`config/job.cloud4.yaml`（steps 30 / g 1.5 / amp 1.3 / seed 1247）
- 旋钮：`audio_amp` 环境变量注入（`src/digital_human/adapters/latentsync.py`），补丁 `patches/latentsync-audio-amplitude.patch`
- 产物：`jobs-cloud/wlh-004-c1~c6/`

### InfiniteTalk（第三阶段，2026-08-20，已出局）
- 产物：`jobs-cloud/wlh-004-it-v2v/output/final.mp4`（448×832/25fps/14.0s/840KB）
- 推理账单：11:38→17:02 共 **5h24m**；350帧÷5段流式×40步×96.6s/步；GPU 4090 满载全程
- 结论：画质无肉眼可见提升（码率 409kbps 偏软），耗时可灵商业版的 ~50 倍于 LatentSync
- 环境档案：`experiments/infinitetalk/FIXES.md`（重装避坑全套）+ `infinitetalk-sdpa-fallback.patch`
- 服务器保留：31GB 权重 + 补丁环境（下次重跑免踩坑；确认出局后可清）

### 5.2 MuseTalk 翻身验证（核心：消"贴图感"）

| 旋钮 | 位置 | 现值 → 建议范围 | 针对 |
|---|---|---|---|
| bbox_shift | `scripts/realtime_inference.py:325` | 0 → ±10 逐试 | 嘴部裁剪框偏移，贴不准 |
| expand | `musetalk/utils/blending.py:35,112` | 1.5 → 1.2/1.8 | 脸框扩张，贴图范围 |
| upper_boundary_ratio | 同上 | 0.5 → 0.4/0.6 | 蒙版上沿（鼻子/脸颊边界痕迹） |
| 高斯模糊核 | `blending.py:81,134`（0.05/0.1×高度） | ×2 / ÷2 | 融合边界羽化，"假"的主嫌 |
| use_saved_coord | 推理参数 | 开 | 复用坐标，排除抖动干扰 |
| 分辨率 | VAE 输入 | 256（硬上限） | 画质天花板，若仍软则判死 |

判定标准：调参后若贴图感仍明显（重点看遮挡手持物、侧脸、说话快切段），则维持"出局"结论；
若明显改善，可作为**快速预览/初稿通道**与 LatentSync 分工（MuseTalk 秒出草稿 → 客户确认语速情绪 → LatentSync 出成品）。
