# 身份证证件替换 — 最终融合方案

> 分支：`feature/idcard-faceswap`
> 日期：2026-08-28
> 状态：**已实现，29/29 测试通过**

---

## 一、业务背景

FaceFusion 换脸已完成后，需要将换好脸的新证件图片贴回「人手持证件」的视频中，替换原来的证件内容。

核心约束：
- 手指捏住证件的区域保留原视频像素
- 替换后亮度/颜色接近原视频，不过曝不突兀
- 证件边缘无亮边/暗边/硬边
- 证件文字清晰不糊
- 输出视频分辨率、FPS、帧数与输入一致

---

## 二、两份原始方案及融合决策

### 2.1 方案 A：GLM5 证件区域替换方案

定位为通用证件区域替换，核心思路：
- 用户手动标注证件四角 → 透视变换贴图
- 用户手动标注手指遮挡多边形 → 保护区 mask
- 工程融入 `src/digital_human/` 现有体系

优势：工程落地性强、视频优先、配置化、测试完备、颜色匹配精细。
劣势：手指需手动标注（操作成本高）、完全没利用「证件与周边有明显色差」这个先验。

### 2.2 方案 B：证件照换脸后处理方案

定位为换脸后贴回，核心思路：
- 用户粗略勾勒区域 → LAB 色差自动分割找卡片精确边界
- 手指因肤色与卡面色差大，自动被排除

优势：减少人工标注、利用了色差先验。
劣势：自动分割不可靠（反光、深色文字/国徽被误分）、没考虑视频、没有工程体系、色彩匹配太简单。

### 2.3 融合决策

| 维度 | 取谁 | 原因 |
|------|------|------|
| 工程位置 | 方案 A | 融入 `src/digital_human/`，复用现有基础设施 |
| 处理对象 | 方案 A | 视频优先 |
| 配置/CLI/标注 | 方案 A | yaml + 标注器扩展，完整可验收 |
| 测试/验收 | 方案 A | 18 条用例，清晰可执行 |
| 卡片定位 | 方案 A | 用户标四角 → `getPerspectiveTransform`（精确） |
| **手指处理** | **融合** | **色差自动检测（方案 B）作为默认，手动 `protect_polygons` 作为 fallback/微调，两者取并集** |
| 色彩匹配 | 方案 A | `exposure_clip` + `chroma_clip` + `shadow_transfer` 更完善 |
| 隐私/安全 | 方案 A | 红线清晰 |

## 三、总体流程

```text
原视频 → FaceFusion 换脸 → facefusion_result.mp4
                                      ↓
                              用户上传新证件图片 (已换脸)
                                      ↓
                              用户标注证件四角 (或 yaml 配置)
                              用户可选标注手指保护区
                                      ↓
                              逐帧处理：
                                ① 透视变换贴图
                                ② 手指保护 mask（手动 ∪ 自动色差检测）
                                ③ 小羽化 (2px)
                                ④ LAB 局部颜色匹配
                                ⑤ Alpha 合成
                                      ↓
                              final_with_id_card.mp4
```

### 4.3 单帧处理流程（核心逻辑）

`replace_id_card_in_frame` 每帧执行以下 8 步：

**Step 1 — 透视变换**
```python
src_quad = [(0,0), (W-1,0), (W-1,H-1), (0,H-1)]  # 新证件图四角
M = cv2.getPerspectiveTransform(src_quad, dst_quad)    # dst = 用户标的四角 × 帧像素
warped_card = cv2.warpPerspective(card_image, M, (frame_w, frame_h))
card_mask    = cv2.warpPerspective(全白mask, M, (frame_w, frame_h))  # 0-1 float
```

**Step 2 — 手指保护 mask**
```python
# 手动多边形填充
protect = fillPoly(所有 protect_polygons)  # 用户标的遮挡区域
# 自动色差检测（融合方案 B 的核心贡献）
if auto_detect:
    ref_color = 中心20%×20%区域的 LAB 中值  # 证件参考色
    dist = LAB欧氏距离(每个像素, ref_color)
    non_card = dist > adaptive_threshold  # 非卡面像素
    non_card = 形态学清理 + 连通域过滤(< 0.5%面积)
    protect = max(protect, non_card)  # 取并集
protect = min(protect, card_mask)  # 只在证件区域内保护
```

**Step 3 — 最终替换 mask**
```python
replace_mask = clip(card_mask - protect_mask, 0, 1)
```

**Step 4 — 边缘羽化（小羽化，不糊文字）**
```python
alpha = GaussianBlur(replace_mask, kernel=feather*2+1)  # 默认 2px
```

**Step 5 — LAB 局部颜色匹配**
```python
# 采样区 = erode(replace_mask, 4px) 避开边缘
sample_mask = erode(replace_mask, sample_erode_pixels)
if sample_count < 500:
    # 采样太少，只做简单 L 均值校正
    delta_L = mean_L(原帧) - mean_L(新证件)
    L_corrected = clip(L + clip(delta_L, ±exposure_clip), 0, 255)
else:
    # LAB 三通道均值差校正，带限幅
    for ch in [L, a, b]:
        delta = mean(原帧[ch]) - mean(新证件[ch])
        clip_val = exposure_clip(ch=0) / chroma_clip(ch=1,2)
        新证件[ch] += clip(delta, ±clip_val)
    # 可选：阴影低频迁移
    if shadow_transfer:
        low_delta = GaussianBlur(原帧, σ=25) - GaussianBlur(新证件, σ=25)
        新证件 += clip(low_delta)  # 只迁移大范围光照变化
```

**Step 6 — Alpha 合成**
```python
result = 原帧 × (1 - alpha) + 颜色校正后新证件 × alpha
```

### 4.4 自动手指检测算法（融合方案 B 的精华）

利用中国居民身份证的视觉先验：卡面底色为白色/浅灰，手指是肤色，**色差明显**。

```
输入：帧 + card_mask（证件区域）
  ↓
在 card_mask 内取中心 20%×20% → LAB 中值 = 证件参考色
  ↓
计算每个像素与参考色的 LAB 欧氏距离
  ↓
阈值分割：距离 > adaptive_threshold = 非卡面
  ↓
形态学清理：闭运算填文字小孔 + 开运算去噪点
  ↓
连通域过滤：面积 < 卡面 0.5% 的区域丢弃
  ↓
输出：非卡面 mask（= 手指/遮挡区域）
```

自适应阈值 = `percentile(证件区域内距离, 75) × 1.8`，最小 30。这样即使不同视频的曝光不同，阈值也能自适应。

## 五、首版能力边界

### 支持
- 单个证件区域
- 证件在视频中基本稳定，只有轻微抖动
- 用户手动标注证件四角
- 用户手动或自动检测手指遮挡区域
- 视频和图片

### 首版不支持
- 证件大幅移动、旋转、透视变化
- OCR 读取证件文字
- 生成式 inpainting
- 多个证件同时复杂替换
- `tracking.mode` 仅 `fixed`，后续可加 `keyframes`/`klt`

---

## 六、隐私与安全

- 不 OCR 证件
- 不把身份证号、姓名、地址写进日志/测试/Git
- 测试使用虚构证件图
- 真实素材只能放在 `.gitignore` 排除的本地目录
- 只用于授权的视频编辑和内容制作
