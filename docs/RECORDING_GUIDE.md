# iPhone真人驱动录制规范

## 你说什么

只说任务配置 `script` 的文字。程序先生成 `recording_guide.wav` 和 `recording_script.txt`；录制时以导读音频的每个字、停顿和句尾为时间基准。

推荐戴单边耳机播放导读，另一只耳朵听自己发声。可以轻声跟读，也可以无声对口型，因为iPhone音轨最终会被丢弃；不能用自己的自然语速另录一遍。

## 设备设置

- 1080p、30fps；关闭电影模式、慢动作、滤镜、美颜和HDR。
- 固定手机，不用手持；镜头与眼睛大致同高。
- 正面柔光，避免嘴部一半强光一半阴影。
- 脸部建议至少约500像素宽，完整包含额头、耳侧和下颌。
- 背景不限，系统不会把操作者背景迁移给客户。

## 表演要求

- 开始前保持约0.5秒正脸、闭嘴、自然表情。
- 跟导读自然发音，嘴唇、脸颊和下颌正常参与，不故意夸张。
- 不左右转头、不低头看稿、不频繁眨眼、不耸肩。
- 结束后保持约0.5秒自然闭嘴再停止。
- 录错字、漏字、抢拍或明显慢拍，应整段重录，不靠剪辑拼字。

## 不需要匹配客户

操作者不需要与客户同身高、胖瘦、性别、服装或背景。系统只提取面部运动。若双方胡须、嘴唇厚度或下颌结构差异极端，结果可能下降，应通过倍率和`exp/lip` A/B选择，而不是要求客户改变形象。

## 文件交付

保留iPhone原始MOV，不用微信转发压缩。复制为 `samples/driving.mov`，并配置：

```yaml
driving_video: "../samples/driving.mov"
```

程序自动裁剪驱动脸、转为25fps并在允许阈值内校正总时长。
