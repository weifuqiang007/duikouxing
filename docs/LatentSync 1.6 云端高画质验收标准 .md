# LatentSync 1.6 云端高画质验收标准

## 1. 验收素材

至少三组已授权、3～10 秒测试片：

1. 1080p 正脸、白底、无手持物。
2. 1080p 正脸、手持虚构证书。
3. 720p 低码率、手持虚构身份证（质量下限组）。

每组使用同一音频同时生成 MuseTalk 基线和 LatentSync 候选。

## 2. 功能验收

| ID | 验收项 | 通过条件 |
|---|---|---|
| F-01 | 引擎选择 | `lipsync.engine=latentsync_1_6` 时不调用 MuseTalk |
| F-02 | 官方版本 | 提交号等于 `a229c3948406bc2cf6eaf4873e662e70c6a04746` |
| F-03 | 权重 | 1.6 UNet、Whisper、auxiliary 和 VAE 齐全，任务中不下载 |
| F-04 | 分辨率 | 日志显示 `stage2_512.yaml` / 512，不是 256 |
| F-05 | 时序 | 官方配置 `num_frames=16` |
| F-06 | 声音 | 继续使用 dots.tts 已验证链路 |
| F-07 | 时长 | 最终视频与目标音频差不超过 1 帧 |
| F-08 | 格式 | H.264 yuv420p + AAC MP4，常见播放器可播放 |
| F-09 | 质量封装 | LatentSync CRF13 视频流被 copy，最终阶段不重编码 |
| F-10 | 可审计 | manifest 记录引擎、提交、参数、输入/输出哈希 |
| F-11 | 授权门禁 | `consent_confirmed=false` 时拒绝运行 |

## 3. 口型同步验收

- 1× 播放无持续闭嘴说话、张嘴无声或明显抢拍/拖拍。
- 人工抽查至少 12 个语音事件：`b/p/m`双唇闭合、`a`大开口、`i`横向嘴型。
- 12 个事件中至少 10 个在听感时点前后约 80ms 内出现对应嘴型。
- 不得出现连续 3 帧以上的牙齿黑块、舌头突变或嘴唇消失。
- 在 0.25× 播放中，嘴角、脸颊和下颌运动连续，不得有固定椭圆贴片。

## 4. 视频质量验收

- 嘴唇边缘在 1× 下可辨识，不是连续的柔化色块。
- 张嘴时上下牙齿与嘴唇有明确边界，不是一块纯白纹理。
- 生成区外的额头、眼睛、耳朵和发型不得因二次编码显著软化。
- 下半脸皮肤清晰度与上半脸处于同一视觉等级，不得有明显“美颜区”。
- 工程筛查指标：下半脸皮肤环带的中位 Laplacian 方差不低于原片同区域的 65%。
  该指标只用于发现异常模糊，不替代人工观感。

## 5. 画面保护验收

- 手、衣服、广告牌、证书和身份证的几何位置不变。
- 证件照片、文字、二维码和印章无生成式改写。
- 对人脸区外指定保护矩形与基底视频做帧对齐比较，忽略 H.264 误差后 SSIM 不低于 0.98。
- 人工逐项核对字段；任何证件内容变化均为验收失败。

## 6. 盲测验收

至少 5 人参与，隐藏引擎名和参数：

- “口型与声音匹配”平均分不低于 4/5。
- “嘴部自然”平均分不低于 4/5。
- “嘴部清晰”平均分不低于 4/5。
- 至少 4/5 参与者认为 LatentSync 候选明显优于 MuseTalk 基线。
- 如果评分未达标，不得以单帧截图替代视频验收。

## 7. 稳定性验收

- RTX 4090 24GB 上完成一个 30 秒 720p 任务，无 OOM、无崩溃。
- 连续完成 3 个 5 秒 A/B 任务，产物不串任务。
- 中间文件存在时可跳过已完成的 TTS 阶段。
- 失败任务不得损坏其他 `job_id` 目录。

## 8. 最终通过条件

F-01～F-11 全部通过；三组素材中至少两组通过口型、视频质量、画面保护和盲测验收；
第三组如失败，必须确认是输入素材质量下限导致，才可进入长视频集成。
