## 其他大模型开发约束

1. 修改依赖前必须引用对应官方仓库文件，不得根据记忆猜版本。
2. 不得把 dots.tts 和 MuseTalk 合并到同一环境。
3. 不得引入云端 API 或自动上传。
4. 不得把原片嘴唇/脸颊/下颌的低频动作贴回 MuseTalk 结果；原片只可提供高频纹理。
5. 不得在未通过 10 秒样片验收前开发长视频批量功能。
6. 不得把“方言支持”写成通用承诺，必须基于真实样本测试。
7. 每次模型升级都要重新执行完整验收集。
